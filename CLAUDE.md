# Projekt: Steffi's Haarstudio Flintsbach

## Was ist das
- Probe-/Designstudie einer One-Page-Website für „Steffi's Haarstudio" in Flintsbach am Inn
- Referenzprojekt für DT Webstudio (kein bezahlter Kundenauftrag)
- **Keine offizielle Website** des Salons

## Design
- Warm, elegant, boutique-editorial
- Farben: warmes Papier #f6f1ec, warmes Tinten-Schwarz, ein Akzent in Pflaume/Rosewood #743c57
- Schriften: Cormorant Garamond (Headlines), Outfit (Text)
- Light Theme, mobile-first, voll responsive

## Tech
- Statisches HTML + CSS + JS, keine Build-Tools, keine Frameworks
- index.html = gesamte Seite, style.css = Styles, script.js = Nav + Scroll-Reveal
- Galerie: aktuell lizenzfreie Unsplash-Beispielbilder (per CDN), klar als „Beispielbilder" gekennzeichnet; später durch echte Salonfotos in img/ ersetzen
